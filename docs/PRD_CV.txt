Phase 2: CV Parsing & Input Validation
Goal: Successfully extract text from uploaded PDF and validate inputs.

Requirements for Cursor:

In app.py:

When “Analyze” is clicked:

Validate that a job description is provided and a file is uploaded.

If missing, show clear error using st.error.

If inputs are valid:

Use PyPDF2.PdfReader to read the uploaded PDF.

Extract text from all pages and concatenate into a single string cv_text.

Handle errors:

If PDF is encrypted/invalid, show st.error("Could not read this PDF. Please upload a text-based PDF CV.").

Display the first 500 characters of extracted CV text in an expandable section for debugging (e.g., st.expander("Preview CV Text")).

Acceptance: Valid PDF → CV text preview shown; invalid input → helpful error message.
